# Code of conduct

## Expected conduct

Treat each person with respect. Give feedback about the work, not about the person. Use clear and
professional language. Accept corrections. Protect private information.

## Unacceptable conduct

Do not harass, threaten, insult, or discriminate against another person. Do not publish another
person's private information. Do not use sexual content or unwanted sexual attention. Do not stop
other people from taking part in the project.

## Enforcement

Report conduct problems to a project maintainer through a private contact method. Do not use a
public issue when the report contains private information. A maintainer can edit or remove content,
close a discussion, reject a contribution, or temporarily or permanently block a person. The
maintainer must protect the report as far as the law permits.

This code applies in project spaces and when a person represents the project in a public space.
