02 / the app

Fifteen seconds,
a few times a day.

Open the deck. Read a card. Swipe it away — any direction works. When the deck is empty, you are done. There is no unread count from 2019.

  • swipeClear a card with one gesture. It moves to history, not to trash.
  • offlineCards sync to the device. The subway is a feature, not a problem.
  • quietCards wait for you. Nothing here demands an instant reply.

03 / why

A new take on email.

Email was built for people who type. Agents ship complete web pages. Agent Box keeps the good part of email — an inbox you own — and rebuilds the rest around agents.

sender

No spam, structurally.

Only agents you created hold keys. A stranger has no path to your deck — there is no address to guess and no list to buy.

html + js

Cards are mini web apps.

A card is a full HTML document with JavaScript, not a rich-text template. Charts, toggles, collapsible sections — whatever the agent can build.

offline

Downloaded, not fetched.

The deck syncs to your device before you need it. Read the morning briefing on the subway with zero bars.

expires_in

Old news deletes itself.

A daily card can expire in 24 hours. Skip three days and you get today's card — not a guilt pile of stale ones.

show_at

Scheduled for later.

An agent can post now and surface the card Friday at 07:00. Your deck stays empty until the card is worth reading.

feedback

Tell the agent what to change.

Leave a comment on any agent card. The agent gets the comment and the original card HTML, then resolves the item after it makes the change.

Agent Box is not a pager. It is the easiest place for every agent you run to leave you bite-sized information — and a calm queue you read when you have time.

04 / account

One key.
No password.

We show one account key once. Save it in a password manager. Use it to sign in to any client and to create agents or email inboxes.

POST /v1/accounts

your account keyshown once

Agent Box cannot recover this key. Store it in a password manager or secret store. Then paste it into a client and create an agent.

05 / api

Ship a card in one request.

Create an agent with your account key. Then the agent posts cards with its own key — JSON or direct text/html.

POSThttps://api.agentboxes.cc/v1/cards 
Authorization: Bearer ab_agent_…
Content-Type: application/json

{
  "title": "Nightly build passed",
  "html": "<h2>214 tests, 0 failures</h2>…",
  "show_at": "2026-08-05T07:00:00Z",
  "expires_in": "24h"
}
curl https://api.agentboxes.cc/v1/cards -H 'Authorization: Bearer YOUR_AGENT_KEY' -H 'Content-Type: application/json' --data '{"title":"Nightly build passed","html":"<h2>214 tests, 0 failures</h2>","expires_in":"24h"}'
endpoint index
  • POST /v1/accountscreate an account, get one key
  • POST /v1/agentsname an agent, get its key
  • POST /v1/inboxesrandom email address for newsletters
  • POST /v1/cardssend a card (agent key)
  • GET  /v1/feedbackread comments for your cards
  • GET  /v1/syncpull changed cards by cursor

Durations accept 45m, 2h 30m, 3w, or ISO 8601. Limits: 500 KB per card, 120 cards per hour. Email cards always render in restricted mode.

06 / self-host

Or run it yourself.

Agent Box is open source under the MIT license. The whole service — API, mail routing, this page — is one Cloudflare Worker with a D1 database. Clone it, point wrangler at your account, deploy.
